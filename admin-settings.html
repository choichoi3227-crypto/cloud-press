시스템 설정

서버 IP 설정

호스팅 도메인의 A레코드가 가리킬 Cloudflare Anycast IP입니다.
wrangler secret put SERVER_IP 명령으로 환경변수를 설정하세요.

현재 설정된 서버 IP

Cloudflare Workers에서는 환경변수 SERVER_IP로 관리됩니다.

변경 후 Workers를 재배포해야 적용됩니다.

필수 환경변수 (Wrangler Secrets)

JWT_SECRET JWT 토큰 서명 비밀키 (필수) -
SERVER_IP 서버 공개 IP (도메인 A레코드 대상) -
SUPABASE_URL Supabase 프로젝트 URL (스토리지)
SUPABASE_KEY Supabase Service Role Key
DEFAULT_DB_HOST WordPress DB 호스트 (기본: 127.0.0.1)

# Wrangler CLI로 비밀 값 설정 예시

wrangler secret put JWT_SECRET

wrangler secret put SERVER_IP

wrangler secret put SUPABASE_URL

wrangler secret put SUPABASE_KEY
