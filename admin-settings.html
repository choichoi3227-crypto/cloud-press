CloudPress CMS 배포 설정

미설정

CMS zip 파일을 업로드하고 GitHub 레포를 지정하면, 호스팅 생성 시 CMS 파일이 자동으로 레포에 업로드되고 Cloudflare Workers에 즉시 배포됩니다.
업로드된 CMS는 각 호스팅의 WordPress 관리자 패널로 동작합니다.

CMS 파일 업로드 (zip)

cloudpress-cms-main.zip을 업로드하세요. 파일은 D1에 base64로 저장되며, 호스팅 생성 시 GitHub 레포에 자동 전개됩니다.

클릭하거나 zip 파일을 드래그하세요

최대 50MB · .zip만 허용

CMS GitHub 레포 & 배포 토큰

CMS 파일이 올라갈 GitHub 레포를 지정합니다. 레포가 없으면 자동 생성됩니다. 여기서 입력하는 토큰은 CMS 배포 전용으로, 사이트별 파일 토큰과 별도로 관리됩니다.

예: myorg/my-cloudpress-cms

권한: repo 토큰 발급

GitHub 스토리지 토큰 관리

로딩 중...

WordPress 코어 파일, 미디어, 테마, 플러그인을 GitHub Private Repository에 저장합니다.
여러 개의 토큰을 추가하면 API rate limit을 자동으로 분산합니다. 토큰은 무제한으로 추가 가능합니다.

새 토큰 추가

GitHub → Settings → Developer settings → Personal access tokens 에서 발급. 권한: repo (private repos 접근)

 필수 환경변수 (Wrangler Secrets)

        
아래 환경변수를 wrangler secret put 명령으로 설정하세요.

        

            

                JWT_SECRET
                JWT 토큰 서명 비밀키 (필수)
                -
            

            

                CF_ACCOUNT_ID
                Cloudflare 계정 ID (Worker/D1/KV 생성용)
            

            

                GITHUB_TOKEN
                기본 GitHub 토큰 (위 UI에서 추가하는 것 권장)
            

            

                DEFAULT_DB_HOST
                WordPress DB 호스트 (기본: 127.0.0.1)
            

        

        

            
# Wrangler CLI로 비밀 값 설정 예시

            
wrangler secret put JWT_SECRET

            
wrangler secret put CF_ACCOUNT_ID

            
wrangler secret put GITHUB_TOKEN

                토스 페이먼츠 결제 설정
            

            요금제 페이지에서 스타터·프로 플랜 결제에 사용
        

        

            호스팅 단위 요금제 결제에 사용됩니다. 무료 플랜은 결제가 필요 없으며,
            스타터·프로 플랜만 실제 결제가 진행됩니다.
        


        

            
            

                보안 주의: Secret Key는 절대 클라이언트(브라우저)에 노출되어서는 안 됩니다.
                Client Key만 프론트엔드에서 사용하고, Secret Key는 서버사이드에서만 사용합니다.
            

        


        

            

                
                
                
토스페이먼츠 → 내 상점 → API 키 → Client Key

            

            

                
                
                
토스페이먼츠 → 내 상점 → API 키 → Secret Key

            

        


        

            
결제 흐름

            

                

                    
무료 플랜

                    
별도 결제 없음
즉시 활성화

                

                

                    
스타터 플랜

                    
토스 페이먼츠 결제
호스팅 단위 적용

                

                

                    
프로 플랜

                    
토스 페이먼츠 결제
호스팅 단위 적용

                

            

            

                
                요금제는 계정 단위가 아닌 호스팅 단위로 적용됩니다.
                사용자는 요금제 페이지에서 결제를 진행합니다.
