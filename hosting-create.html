Cloudflare Pages 호스팅이란?
  • WordPress 공식 파일을 Astro 코드로 자동 변환
  • GitHub 레포지토리 = 스토리지 (변환된 코드 보관)
  • Cloudflare Pages = 배포 (GitHub 레포 미러링·빌드)
  • D1 DB + KV 바인딩 자동 연동
  • 구축 시간: 5~8분

호스팅 플랜 안내 (중요)
  • 호스팅 플랜에는 스토리지·DB가 기본 포함되지 않습니다.
  • DB: 자체 코드로 작성(무료) 또는 CloudPressDB 구독 후 연결
  • 스토리지: AWS S3, GCP, Azure, 네이버클라우드, 구글드라이브, CP3 중 선택 연결
  • PHP는 Astro로, JS는 TypeScript로 실시간 자동 변환되어 배포됩니다.
