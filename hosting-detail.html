Cloudflare 네임서버 인증 방식

도메인을 등록하면 Cloudflare Zone이 자동 생성되며 네임서버(NS) 정보가 제공됩니다.
도메인 등록기(가비아, 후이즈, GoDaddy 등)에서 네임서버를 Cloudflare NS로 변경하면 자동 활성화됩니다.

인증 절차

① 아래 입력란에 도메인 입력 후 [추가] 클릭

② 제공된 Cloudflare 네임서버 2개를 도메인 등록기에서 변경

③ [네임서버 확인] 버튼으로 전환 완료 확인

DNS 전파는 최대 24~48시간 소요됩니다.
