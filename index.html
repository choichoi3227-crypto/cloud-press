왜 CloudPress인가요?

기존 호스팅의 한계를 Cloudflare 엣지 기술로 극복했습니다.

엣지 캐싱 가속

사용자와 가장 가까운 엣지 노드에서 콘텐츠를 직접 제공합니다. 전통적인 CDN과는 달리 PHP 실행까지 엣지에서 처리됩니다.

무료 SSL 자동 발급

모든 도메인에 HTTPS가 자동으로 적용됩니다. 인증서 만료 걱정 없이 영구적으로 무료 SSL을 사용하세요.

D1 서버리스 DB

Cloudflare D1 기반 SQLite 데이터베이스. 서버 없이 글로벌하게 데이터를 분산 저장하며 자동으로 동기화됩니다.

자동 백업

매일 자동으로 스냅샷을 생성하고 Cloudflare R2에 안전하게 보관합니다. 1클릭으로 특정 시점으로 복원하세요.

실시간 트래픽 모니터링

대시보드에서 방문자 수, 대역폭, 응답 시간을 실시간으로 확인합니다. 이상 감지 시 즉시 알림을 받으세요.

커스텀 도메인 연결

보유한 도메인을 손쉽게 연결하세요. DNS 전파 없이 즉시 적용되며 www/naked 도메인 모두 지원합니다.

FAQ

자주 묻는 질문

CloudPress는 서버가 아닌 Cloudflare의 엣지 네트워크에서 PHP WASM 런타임을 통해 워드프레스를 실행합니다. 전 세계 어디서든 동일한 속도를 보장하며, 트래픽 폭증 시 자동으로 스케일링되어 다운타임이 없습니다.
네, 가능합니다. All-in-One WP Migration 플러그인 또는 Duplicator를 사용하여 기존 사이트를 내보낸 후 CloudPress에 가져올 수 있습니다. 이전 가이드 문서도 제공하고 있습니다.
무료 플랜은 워드프레스 사이트 1개, 월 100GB 트래픽, 5GB 스토리지가 제공됩니다. 커스텀 도메인 연결은 스타터 플랜부터 지원합니다. 무료 플랜은 기간 제한 없이 영구적으로 사용하실 수 있습니다.
대부분의 워드프레스 플러그인이 정상 작동합니다. 단, 서버 직접 접근(SSH exec, shell_exec 등)을 요구하는 일부 플러그인은 서버리스 환경 특성상 지원되지 않을 수 있습니다. WooCommerce, Yoast SEO, Elementor 등 주요 플러그인은 모두 호환됩니다.
카카오페이, 토스, 신용카드/체크카드, 계좌이체 등 국내 주요 결제 수단을 모두 지원합니다. Toss Payments를 통해 안전하게 결제되며, 구독은 언제든지 취소할 수 있습니다.
