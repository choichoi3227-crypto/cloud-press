강력한 보안

무한 스토리지

36개 Supabase 버킷 샤딩과 4개 백업 노드로 데이터 손실 걱정 없이 무제한 확장하세요.

WASM PHP

PHP 코드를 WebAssembly로 변환하여 서버리스 환경에서 네이티브에 가까운 속도로 실행합니다.

자주 묻는 질문

CloudPress는 어떻게 작동하나요?
CloudPress는 Cloudflare Workers의 엣지 네트워크에서 PHP WASM 런타임을 실행하여 워드프레스를 구동합니다. 모든 파일은 Supabase의 분산 버킷에 저장되며, D1 데이터베이스를 사용합니다.
정말 무료인가요?
네, CloudPress는 Cloudflare Workers, D1, KV, 그리고 Supabase의 무료 플랜만을 활용하여 운영됩니다. 사용자는 추가 비용 없이 서비스를 이용할 수 있습니다.
