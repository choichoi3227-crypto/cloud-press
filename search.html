CLOUDPRESS

Free Search + Image Endpoint

검색 스크래핑과 자체 이미지 생성을 URL 하나로 호출

API 키 없이 GET/POST 요청만으로 동작하는 공개 JSON 엔드포인트입니다. 검색 스크래핑뿐 아니라 외부 AI 바인딩 없는 프롬프트 기반 BMP 비트맵 이미지 생성을 Cloudflare 무료 배포 환경에서 실행하도록 구성했습니다.

GET /api/search?q=cloudpress&engine=all
POST /api/image { "prompt": "네온빛 서울 야경" }
지원

engine=google, naver, all

인증

로그인·API 키 불필요

이미지

외부 AI 없이 자체 BMP 생성

정확한 엔드포인트

  • /api/search?q={검색어}&engine=all — Google과 네이버 동시 조회
  • /api/search?q={검색어}&engine=google — Google만 조회
  • /api/search?q={검색어}&engine=naver — 네이버만 조회
  • start=0 — 페이지 시작 위치 옵션

중요: “영원히 무료”, “100% 실시간”, “항상 동일한 결과”는 외부 검색 사이트의 정책·차단·HTML 변경에 의존하므로 기술적으로 보장할 수 없습니다. 이 구현은 플랫폼 비용과 인증키 요구를 없애고 캐시를 비활성화해 가능한 한 실시간으로 요청합니다.

Cloudflare Workers 단독 배포

이 기능만 독립 서비스로 운영하려면 저장소의 wrangler-search.toml 설정을 사용하세요.

npx wrangler deploy -c wrangler-search.toml

주제 조사(Research) 엔드포인트

워드프레스 플러그인(zorlinq32) 등 외부 도구에서 검색 그라운딩·AI 썸네일 주제 조사에 사용할 수 있는 JSON 조사 API입니다. 기존 Groq 기반 워커를 완전히 대체합니다.

POST /api/research
Content-Type: application/json
X-AIBP-Secret: (선택, wrangler secret 등록 시에만 검사)

{ "query": "다이어트 식단", "max_results": 8 }

응답은 providers(검색 원본), summary/results(그라운딩용), research(actual_meaning · visual_context · hero_shot · color_mood · key_visuals · category · emotional_tone · text_color_hex · accent_color_hex)를 포함합니다.

기본적으로 Cloudflare AI 바인딩 없이 규칙 기반으로 동작합니다. 바인딩을 추가하면 요청당 최대 1회, 짧은 프롬프트로만 결과를 보강하도록 설계되어 있으며 이 바인딩은 선택 사항입니다.

자체 이미지 생성 엔드포인트

/api/image는 프롬프트와 선택적 image_url을 latent vector로 변환하고 요청 내부의 coordinate neural field를 여러 step으로 샘플링해 매번 코드가 아닌 실제 BMP 비트맵 이미지를 만듭니다. 외부 API, Cloudflare AI 바인딩, 유료 모델을 호출하지 않습니다.

POST /api/image
Content-Type: application/json

{ "prompt": "네온빛 서울 야경과 고양이 로봇", "image_url": "https://example.com/reference.jpg", "steps": 5, "bitmap_width": 256, "bitmap_height": 256 }

지원 언어 키워드: 한국어, 영어, 일본어, 중국어, 스페인어, 프랑스어, 독일어, 포르투갈어, 베트남어, 태국어, 인도네시아어, 아랍어, 힌디어, 러시아어. 단, 무료 엣지 런타임에서 대형 학습형 모델을 무료 엣지 런타임만으로 능가한다고 검증할 수는 없습니다.
