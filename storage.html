스토리지 관리

워드프레스 미디어 파일과 정적 자산을 위한 외부 스토리지를 연결하세요.

호스팅 플랜에는 스토리지가 포함되지 않습니다. 아래 스토리지 중 하나를 연결하거나, CP3를 구독하여 CloudPress 자체 스토리지를 사용하세요.

스토리지 연결하기

AWS S3
Amazon Simple Storage Service
연결됨

버킷 이름, 리전, Access Key로 연결. 업계 표준 S3 호환 스토리지.

GCP Cloud Storage
Google Cloud Platform
연결됨

GCP 서비스 계정 JSON 키로 연결. 버킷 이름과 프로젝트 ID 필요.

Azure Blob Storage
Microsoft Azure
연결됨

Connection String 또는 SAS Token으로 연결. 컨테이너 이름 필요.

네이버 클라우드 Object Storage
NAVER Cloud Platform
연결됨

S3 호환 API. Access Key와 Secret Key로 연결. 국내 데이터센터.

Google Drive as Storage
연결됨

Google OAuth 인증 후 드라이브 폴더를 스토리지로 사용. 15GB 무료 제공.

Google 계정 인증 및 동의 필요

구글 드라이브 연결

Google 인증 및 동의

아래 버튼을 클릭하면 Google 로그인 페이지로 이동합니다. CloudPress가 구글 드라이브에 파일을 저장·읽기 위한 권한에 동의해야 합니다.

연결 후 동의 사항: CloudPress는 지정된 폴더에만 접근합니다. 다른 파일에는 접근하지 않습니다. 언제든지 Google 계정 설정에서 권한을 철회할 수 있습니다.

OAuth 2.0 보안 인증. CloudPress는 비밀번호를 저장하지 않습니다.
